# 鸿蒙 HDC 安装工具

通过 HDC（HarmonyOS Device Connector）批量安装 `.hap`（应用包）和 `.hsp`（共享包）文件到鸿蒙设备的工具。提供 **图形界面（GUI）** 与 **命令行（CLI）** 两种使用方式。

作者：朱信志

---

## 一、功能特性

- 🖥️ **双模式**：图形界面 + 命令行，满足不同使用场景
- 📦 **批量安装**：支持一次安装多个 `.hap` / `.hsp` 文件
- 🔢 **智能排序**：自动 **先安装 `.hsp`（共享包），再安装 `.hap`（应用包）**，避免依赖缺失导致安装失败
- 📂 **目录扫描**：支持指定目录扫描，可选递归扫描子目录
- 🖱️ **可视化勾选**：GUI 中可逐个勾选/取消待安装文件，支持全选/取消全选
- 📱 **多设备管理**：自动检测已连接设备，多设备时可选择目标设备
- ⚠️ **签名错误诊断**：自动识别签名/证书类错误，并尝试获取设备 UDID，给出修复指引
- 🎨 **彩色日志**：GUI 日志按成功/失败/警告/信息分色显示
- 👀 **dry-run 预览**：CLI 支持仅预览将安装的文件而不实际执行

## 二、环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（已测试） |
| Python | 3.10+（源码运行时需要；使用打包版 exe 无需安装 Python） |
| HDC 工具 | 已安装并加入系统 `PATH` 环境变量（随 DevEco Studio 附带） |
| 设备 | 已开启「开发者模式」并允许「USB 调试」的鸿蒙设备 |

> 检查 HDC 是否就绪：在命令行执行 `hdc version`，能输出版本信息即说明环境正常。

## 三、快速开始

### 方式 1：使用打包版（推荐普通用户）

直接双击运行 `dist/鸿蒙HDC安装工具.exe`，无需安装 Python。

### 方式 2：源码运行

```bash
# 启动图形界面
python hdc_installer.py --gui

# 或直接运行 GUI 入口
python hdc_gui.py
```

## 四、图形界面（GUI）使用说明

启动后界面分为五个区域：

```
┌─────────────────────────────────────────────┐
│  作者：朱信志                                 │
├─────────────────────────────────────────────┤
│ 设备区    [选择设备 ▼]  [刷新设备]            │
├─────────────────────────────────────────────┤
│ 路径区    [路径____] [浏览目录][浏览文件] ☐递归│
├─────────────────────────────────────────────┤
│ 待安装文件  ☑ 文件名                          │
│            ☑ 文件名      [全选][取消全选]     │
├─────────────────────────────────────────────┤
│ [开始安装]                       [清除日志]   │
├─────────────────────────────────────────────┤
│ 安装日志（彩色）                              │
├─────────────────────────────────────────────┤
│ 状态栏                                       │
└─────────────────────────────────────────────┘
```

### 操作步骤

1. **连接设备**：用 USB 连接鸿蒙设备，确认已开启 USB 调试
2. **刷新设备**：点击「刷新设备」，下拉框中选择目标设备（单设备会自动选中）
3. **选择文件**：两种方式
   - 「浏览目录」：选择包含安装包的目录，自动扫描其中的 `.hap`/`.hsp`
   - 「浏览文件」：直接多选具体的安装包文件
   - 勾选「递归扫描子目录」可扫描子目录下所有匹配文件
4. **勾选文件**：在文件列表中点击每行前的 ☑/☐ 切换是否安装；也可用「全选/取消全选」
5. **开始安装**：点击「开始安装」，日志区实时显示进度
6. **查看结果**：安装完成后日志区与状态栏显示成功/失败统计

### 日志颜色含义

| 颜色 | 含义 |
|---|---|
| 🔵 蓝色 | 普通信息 / 进度 |
| 🟢 绿色 | 安装成功 |
| 🔴 红色 | 安装失败 / 普通错误 |
| 🟠 橙色 | 警告（如签名错误、UDID 提示等） |

> 安装在子线程中执行，界面不会卡死；安装期间「开始安装」按钮会禁用，完成后自动恢复。

## 五、命令行（CLI）使用说明

### 列出已连接设备

```bash
python hdc_installer.py devices
```

### 安装命令

```bash
python hdc_installer.py install <路径> [选项]
```

#### 参数说明

| 参数 | 说明 |
|---|---|
| `path` | 要安装的文件路径或目录路径（必填） |
| `-s`, `--serial` | 指定目标设备序列号（多设备时必填，单设备可省略） |
| `-r`, `--recursive` | 递归扫描子目录 |
| `--dry-run` | 仅预览将安装的文件，不实际执行 |
| `--continue-on-error` | 某个文件失败后继续安装其余文件（默认启用） |

#### 示例

```bash
# 安装单个文件
python hdc_installer.py install app.hap

# 安装目录下所有 .hap/.hsp
python hdc_installer.py install ./packages/

# 递归扫描子目录
python hdc_installer.py install ./packages/ -r

# 指定设备安装
python hdc_installer.py install app.hap -s DEVICE123

# 仅预览，不实际安装
python hdc_installer.py install ./packages/ --dry-run
```

## 六、安装顺序说明（重要）

当同时安装 `.hap` 和 `.hsp` 文件时，工具会 **自动排序**：

```
先安装 .hsp（共享包）  →  再安装 .hap（应用包）
```

**原因**：`.hap` 应用包可能依赖某些 `.hsp` 共享包。若先装 `.hap`，可能因依赖的共享包尚未安装而失败。按 `.hsp` → `.hap` 顺序安装可避免此问题。

同类文件内部按文件名升序排序。

## 七、常见问题

### 1. 提示「找不到 hdc 命令」

HDC 未加入系统 `PATH`。请将 DevEco Studio 安装目录下的 `toolchains/hdc` 路径添加到系统环境变量 `PATH` 中。

### 2. 提示「未检测到已连接的鸿蒙设备」

请检查：
- 设备是否通过 USB 正确连接
- 设备是否开启了「开发者模式」
- 是否在设备上允许了「USB 调试」

### 3. 安装失败：签名/调试证书相关错误

日志中出现 `signature`、`cert`、`udid` 等关键字时，工具会自动给出诊断信息。通常意味着设备的 **UDID 未添加到调试签名配置中**。解决步骤：

1. 获取设备 UDID：
   ```bash
   hdc shell bm get -u
   # 或
   hdc shell param get const.ohos.serial
   ```
   （工具会自动尝试获取并显示在日志中）
2. 前往 [华为开发者中心](https://developer.huawei.com) → 「证书管理」→「调试证书」，将设备 UDID 添加到调试设备列表
3. 重新生成调试签名 Profile
4. 用新的 Profile 重新签名 `.hap`/`.hsp` 文件
5. 重新运行安装

### 4. hdc 命令执行超时

单条命令超时阈值为 120 秒。若设备响应过慢或安装包过大，可能触发超时。请检查设备连接稳定性后重试。

## 八、项目结构

```
hmhdc/
├── hdc_installer.py          # 核心逻辑 + CLI 入口
├── hdc_gui.py                # Tkinter 图形界面
├── 鸿蒙HDC安装工具.spec       # PyInstaller 打包配置
├── packages/                 # 安装包存放目录（示例）
├── build/                    # 打包中间产物（自动生成）
└── dist/
    └── 鸿蒙HDC安装工具.exe    # 打包输出（最终可执行文件）
```

### 核心模块

| 模块 | 职责 |
|---|---|
| `HdcRunner` | 执行 hdc 命令（`run` / `list_devices` / `install` / `get_device_uid`），解析安装错误 |
| `DeviceManager` | 设备选择与校验逻辑 |
| `FileScanner` | 扫描指定路径下的 `.hap`/`.hsp` 文件 |
| `Installer` | 批量安装执行器，负责排序与进度输出 |
| `HdcApp` | GUI 主应用 |

## 九、构建打包

使用 PyInstaller 打包为单文件 exe：

```bash
python -m PyInstaller "鸿蒙HDC安装工具.spec" --clean --noconfirm
```

打包产物：`dist/鸿蒙HDC安装工具.exe`

> `.spec` 文件已配置将 `hdc_installer.py` 作为数据文件一并打包，GUI 模式下可正常导入。`console=False` 表示不显示控制台窗口（纯 GUI 运行）。

## 十、退出码

CLI 模式退出码：

| 退出码 | 含义 |
|---|---|
| `0` | 全部安装成功（或 devices 命令正常执行） |
| `1` | 存在安装失败，或扫描无文件、设备选择失败等异常 |
